### 2026-10-04 模型 API 丢失回执保护

- 根因：API 模型请求的传输超时由连接器包装成普通 `Problem`，调用账本因此记为 `failed`。虽然相同 request key 会被阻止重放，但失败状态没有告诉操作员“请求可能已送达”，容易诱发换新 request key 后盲目再次付费。
