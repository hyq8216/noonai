# 紧凑业务导航

本轮按用户选择“只展开当前组，切换时自动展开”实现；基于云端
`codex/erp-deepening-0.44.0` 的 `d17afcf`，保留全部40个页面与六模块深化。
默认打开批量铺货。运营总览独立直达，其余入口归入六组。

| 一级组 | 二级入口与子组 | 三级入口 |
| --- | --- | --- |
| 商品铺货 | 批量铺货、商品库、导入货源、批量刊登与结果；采集与来源、商品与素材 | 国内来源与候选、国内网页采集、周期采集、导入字段模板；SPU与规格组、商品批量编辑、图片与视频、电商视觉制作 |
| 订单履约 | 订单履约、订单批量导入、批量拣货发货、物流包装与交接、售后与退款 | 无 |
| 采购库存 | 采购管理、库存管理 | 供应商询价比较、采购收货、采购订单关联；库存台账、库存补货建议、批量库存盘点、调拨与补货 |
| 财务经营 | 经营分析、价格方案预检、广告归因分析；财务对账 | 财务与对账、结算文件核对、银行流水核对、汇率档案 |
| 自动化 | 自动化中心、异常中心、任务与记录 | 无 |
| 系统设置 | 业务档案、模型服务、连接设置；资料备份 | 备份与恢复、周期备份 |

展开另一组时收起原组；只折叠菜单不会导航、保存或放弃表单。页面按钮跳转和
搜索跳转使用原有`leave()`保护，确认成功才打开目标的父组并清空功能搜索。
取消离开保留原页面、草稿和搜索。数据刷新保留手动收起及滚动位置。

功能搜索匹配页面名、路由、组名及业务别名，如1688、模特照、Codex；搜索期间
显示所有匹配层级，清空后恢复原折叠状态。Escape清空搜索；唯一结果可Enter进入。
展开控件使用原生button、aria-expanded与aria-controls，隐藏子项不参与Tab顺序。
顶部显示当前二/三级路径，避免在复杂业务页面中迷失。

窄屏默认只显示品牌与“打开菜单”；菜单内滚动，进入页面后收起。
`scripts/browser/navigation.cjs`验证披露、搜索、键盘、取消/接受离开和草稿保护。
原业务脚本通过`navigation_helpers.cjs`实际点击父菜单，继续验证40页及业务流程；
不通过隐藏控件或直接调用navigate绕过用户交互。移动菜单关闭时当前路由仍存在于DOM，
所以当前路由检查使用attached，页面标题和main的data-view另行验证。

本轮只改导航及发布编排，业务权限、任务回执、商品版本、人审与真实平台边界不变。
精确检查与安装包记录见[VERIFICATION.md](VERIFICATION.md)。
