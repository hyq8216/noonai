# 国内采集质量与批量诊断深化

2026-10-03。本次只深化现有1688、淘宝/天猫、拼多多资料包预检和页面，不新增导航或接口路由；保留来源候选和商品入库两次明确确认。

## 已交付

- 既有 `POST /api/domestic-capture/preview` 增加逐行 `quality`：稳定问题码、字段、严重度（blocker/warning/info）、可执行核对动作、明确未知字段、采集方法、网页原规格和当前有效规格。缺SKU禁止建商品；供应商和事实缺失指向有依据的人工校对；售价/数量/图片缺失指向来源核对，不能通过文字校对填写价格或库存。
- 对已有来源观察的冲突列出历史最新原值与本次原值变化；原normalized事实和已有商品仍不覆盖。重复观察区分历史重复与包内首次行号，后者指向第一行；包内同身份不同事实仍拒绝整包。
- 批量 `quality_summary` 包含观察行数、来源商品数、独立规格身份数、需核对和阻断行数、逐问题数量、未知字段数量、采集方法数量、扩展提示。统计按观察行计算，不把零售价或零数量计为未知。
- 页面就地筛选全部、需核对、阻断或某类问题；筛选只隐藏行，草稿和明确确认保持。页面明确确认仍处理完整资料包，避免筛选被误认为选择性导入。
- 导出当前筛选诊断CSV：本地Blob下载、UTF-8 BOM、双引号转义、未知值标记、零值保留；公式前缀（含前导空白及制表符）加单引号。只导出诊断字段，不导出完整原包、校对依据或浏览器数据。草稿变化立即禁用导出、撤销录入确认，重新预检后恢复。

## 限制

诊断解释已通过安全校验的观察，缺币种、非CNY、恶意域、敏感字段和包内同身份不同事实仍按原安全契约拒绝整包。缺字段提示不代表已核实供应商、数量、事实或素材权利；采购成本始终独立待确认。CSV供问题处理和核对，不是商品导入模板。本次没有真实平台账号、线上DOM或官方API验证，没有登录、采集账号、卖家写入、模型付费或付款操作。
