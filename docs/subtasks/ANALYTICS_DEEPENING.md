# 经营分析深化（2026-10-03）

在现有经营分析页面和 `/api/analytics/state`、`/api/analytics/export` 内交付；未新增导航或路由。

## 交付

- 日趋势连续补零，最多366天；周趋势从周一开始，首尾周截断到筛选窗口。创建订单、未取消订购件数、发货件数、登记退货件数分别按自身UTC证据日期汇总。
- 自动比较紧邻同长度上期，展示范围、绝对差和百分比；上期为零时百分比为未知，CSV留空。上期日期无法表示时返回明确业务错误，而非日期溢出。
- 收入、费用按有效凭证确认日期与原币整数分展示，不合并币种、也不重复确认收付款。全局包含未分摊金额；店铺/仓库筛选只汇总匹配订单的原币分摊份额。CNY贡献继续复用现有财务尾差分摊，不改既有核对合同。
- SKU显示当前有库存但至少30天观测期内无发货、登记退货需核对原因、参考成本缺失、无可用库存等提示，并逐行显示观测窗口。提示不证明库存存在满30天、库龄、完整销售历史或滞销事实，不从不同订单批次计算退货率。
- 页面可切日/周粒度；CSV同时包含两种趋势、上期比较与本页SKU风险证据，沿用CSV公式转义、BOM与既有分页。
- 趋势仅增加4个按证据日期分组的订单查询和1个原币凭证汇总查询；不逐日重复扫描或调用财务贡献计算，日期筛选在分组前执行。

## 限制

报表使用当前本地单据状态和已登记事件；不能证明外部完整订单历史、真实Noon经营、历史库存周转、库龄、成本结转或净利润。库存仍是生成时快照。上期比较不做季节性、归因或汇率调整。全平台和macOS发行验收由主任务汇总。
