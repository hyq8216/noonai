## 全平台扩展顺序（2026-10-03）

用户本次要求的是完整 noon ERP，以下纳入持续交付；已有功能和缺口以
`PLATFORM_SCOPE.md` 为准。这份顺序不是已完成功能清单，账号接口必须逐项确认。

| 阶段 | 功能范围 | 可交付验收 |
| --- | --- | --- |
| 基础可靠性 | 回归修复、队列时间与恢复、防重、分页、大目录性能、操作审计 | 全量检查、实际重启、全部页面桌面/窄屏检查通过；外部未知回执不重发 |
| 商品与铺货 | 授权货源接入、SPU/变体、属性模板、批量编辑、术语/OCR、英阿质检、商品图/视频、托管、刊登与反馈处理 | 同一批次从来源到提交回读可追踪，缺字段和身份冲突逐件隔离；人工审核绑定版本；真实可售单独验收 |
| 交易与供应链 | 店铺订单导入/同步、分仓占用、拣货打包/面单、拆合单、时效异常、采购关联与收货、批次盘点、调拨异常、退货不可售与退款赔付 | 订单—采购—库存—履约—售后单据贯通，数量守恒、重复单据不计账、操作可追溯；平台写入先做授权小样 |
| 财务与经营 | Noon 结算导入、费用/税费/退款分摊、银行匹配、汇率、库存成本结转、期间报表、SKU贡献、库存周转、广告投入分析 | 结算逐行映射并列示差异，原币与本币可核对；报表说明未录成本，不能把台账差额当净利润 |
| 团队与服务 | 多店铺/工作空间隔离、角色权限、审批、通知、周期规则、异地备份、登录/TLS、后台服务与监控 | 跨店铺数据不可见、权限在服务端执行、恢复演练和失败告警可复现；部署与原生分发分别验证 |

沙特站优先；后续 UAE/埃及站点、FBN/FBP 与其他履约模式按实际店铺权限、
接口契约、币种及税费规则验证后接入。价格保护、竞价和广告调整需要独立预算与
审批机制，不能从只读分析直接切换为卖家账户写入。
