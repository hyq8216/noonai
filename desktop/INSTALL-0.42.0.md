# Noon Studio 0.42.0 安装说明

适用于 Apple Silicon（M1/M2/M3/M4 等）Mac，macOS 12 或更新版本。

安装：打开 DMG，把 Noon Studio 拖到 Applications（应用程序）。退出旧版后再启动新版。ZIP 备用包解压后也可把应用拖入应用程序。

已有本机资料使用应用原有的 Application Support/NoonStudio 目录。替换应用包不会主动清空该目录。升级前可使用软件中的备份功能保存业务资料。

本版核心改动：
- 页面直接投递最多 5000 行、20MB 的 CSV/JSON 新商品资料或供货更新，沿用已保存规则，按 500 行分批处理；相同文件内容去重。
- 商品链接候选池：规范化链接、识别已入库/已收集链接、导出待补充资料模板。
- 保存和复用图片制作模板，主图、场景、模特、细节图分别填写要求；参考图片仍需单独指定。
- 批量安排的异常明细可从历史记录导出，方便集中处理跳过和未就绪商品。
- 包含近期货源扫描续接、模型额度重试及图片质量检查的代码改动。

接收文件成功仅表示已保存到投递箱，后续导入结果请查看处理记录。软件关闭时不扫描。模型任务消耗已配置订阅额度，并受服务能力和额度限制。

这是本地开发构建，使用 ad-hoc 签名，未做 Apple Developer ID 签名或公证。本轮依用户要求暂不进行功能测试；构建和签名结构检查不证明业务运行成功。真实 noon 店铺上架、1688 授权采集、真实商品成图质量及生成式视频尚未完成端到端验证。
