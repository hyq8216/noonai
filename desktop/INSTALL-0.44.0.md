# Noon Studio 0.44.0 安装说明

本版把40个入口收为运营总览及六组可折叠菜单，保留功能搜索，深层入口按二/三级展开。默认只展开当前业务组，切换页面自动定位；收起菜单不丢弃表单，窄屏可收起整份导航。包含云端采集诊断、规格矩阵、整批报价采购草稿、补货、经营趋势与异常处置六模块深化。

本版包含国内1688、淘宝、拼多多主动网页采集与21项本地业务扩展，共40个工作台页面。
完整功能和限制见仓库 `docs/ERP_DELIVERY.md`。实际Noon经营、多用户服务和平台网站兼容性仍待验收。

## 安装

1. 选择与Mac匹配的包：Apple Silicon（M1/M2/M3/M4等）使用arm64；Intel使用x86_64。
2. 双击DMG，把 `Noon Studio.app` 拖到 `Applications`（应用程序）快捷方式。
3. 退出旧版，再从“应用程序”打开新版；不要直接从磁盘映像内长期运行。
4. 本地开发包采用临时签名，未通过Apple公证。若系统提示开发者无法验证，确认文件来自你自己的构建，再按“系统设置→隐私与安全性”中的“仍要打开”处理；不关闭系统安全设置。

程序内置Python运行环境和FFmpeg，不需要安装Python才能运行。订阅模型功能仍需本机独立安装并登录Codex；保存本地资料不需要平台账号。
构建最低目标为macOS 12；实际支持范围还受构建Mac SDK和内置第三方运行库影响，需在目标Mac实测。

## 资料和升级

资料默认存放 `~/Library/Application Support/NoonStudio`。升级会沿用原资料位置；替换应用前先在“备份与恢复”保存完整备份。
程序和DMG不包含任何经营资料、账号令牌或浏览器登录会话。不要删除资料目录作为升级步骤。

## 国内采集扩展

打开“国内网页采集”，下载扩展ZIP，解压后在Chrome/Edge扩展管理页开启开发者模式，通过“加载已解压的扩展程序”选择含 `manifest.json` 的目录。
在1688、淘宝或拼多多当前商品页主动点击采集按钮，资料包先预检和确认候选，再单独确认商品入库。
不会自动登录，不读取浏览器会话，不能保证所有线上页面已兼容；缺规格或身份矛盾会保留待核对。

## 文件校验

在DMG所在目录运行：

```sh
shasum -a 256 -c Noon-Studio-0.44.0-macOS-arm64.dmg.sha256
```

Intel包把文件名中的 `arm64` 换成 `x86_64`。
校验只能证明与你持有的校验文件一致，不能替代Apple签名、公证或来源可信核对。

## MiniMax 订阅增补构建

本增补包含独立的 MiniMax Coding Plan / M Plan 配置入口，仍沿用0.44.0版本号。
进入“系统设置 → 模型服务 → 新增模型服务”，选择“MiniMax · Coding Plan / M Plan 订阅”。
接口默认 `https://api.minimax.cn/v1`，国际订阅可填写 `https://api.minimax.io/v1`；只支持OpenAI兼容协议。
输入套餐详情提供的订阅Key（通常为 `sk-cp-`），选择M3、M3.1 Flash Preview、M2.7或自定义模型编号。
每日调用上限、每分钟调用上限与输出上限是本软件限制，不代表平台套餐额度。
保存不调用模型；“测试连接”会消耗用量。真实模型权限、扣减和限流以你的套餐为准。
512K通过小批次文本资料与保守长度上限控制，未用真实订阅验证折扣或全天吞吐。
Key只保存在本机独立文件中（未加密、仅当前用户可读写），页面不会回显。

## 调度器增补构建

本增补沿用0.44.0版本号，包含MiniMax订阅配置与调度优化。
空闲队列改为事件等待，新建、恢复、人工审核与模型配置保存会唤醒调度；预约和额度等待的期限仍保留。
批次最后一步完成后及时更新状态；自动化商品卡片显示下次检查时间。
暂停、取消、人工审核和不确定回执核对继续执行；关闭应用或休眠期间不处理任务。
