## 使用

打开 `dist-v25/Noon Studio.app`。应用包含自己的Python服务、视频引擎与运行依赖，无需用户安装Python或打开终端。应用使用本机随机端口，并在原生WebKit窗口中呈现界面。

正常资料目录为 `~/Library/Application Support/NoonStudio`。从“文件 → 打开资料目录”可以找到；`.env` 服务配置放在该目录，重启后生效。应用不自动迁移或覆盖旧 `workbench/data`。两者目前是不同资料库，后续迁移需保留备份。

当前可以进行商品导入/加工、业务档案、采购与部分收货、多仓库存、订单占用/发货/取消/退货。另支持素材库、批量图片模板、视频剪裁与转码、封面、图组视频、加工队列、成品预览和导出。所有运营单据是本地记录，未同步外部平台。

退出时会检查未保存表单。正常退出会关闭自己启动的服务。不要在后台处理外部提交时强制退出；中断任务在下次启动后需要核对。

## 构建

在项目根目录，使用 Python 3.12 创建 `desktop/.venv`，安装 `requirements-build.txt`，执行：

```sh
desktop/.venv/bin/python desktop/build.py
```

需要Apple命令行开发工具（Swift与SDK）。只清理并重建脚本自己生成的 `desktop/dist/Noon Studio.app`，不触碰用户资料目录。

打包依据：[PyInstaller官方运行模式](https://pyinstaller.org/en/stable/operating-mode.html)；客户端采用Apple原生 [WKWebView](https://developer.apple.com/documentation/webkit/wkwebview)。

## 测试与证据

```sh
desktop/.venv/bin/python -m unittest discover -s workbench/tests -v
```

测试工作空间放在 `desktop/qa`，不用于经营。`NOON_STUDIO_DATA`可指定独立的测试资料目录，`NOON_SMOKE_OUTPUT`可让原生窗口在首次载入后输出UI状态与截图；生产默认不输出这些测试证据。

完整功能目标、当前证据与仍未完成项见项目根目录 `PLATFORM_SCOPE.md`。

## 媒体加工 0.3

在「图片与视频」批量导入素材，填写使用依据，勾选素材并配置配方，然后创建处理任务。拼版与图组视频按选中顺序合成，可用箭头调整顺序。单图模板按素材分别生成；原文件不被覆盖。视频时间留空使用剩余时长（最多180秒），封面只填写开始秒数。素材最长视频10分钟、单文件100MB；单批导入12个、批处理最多50项。

图片模板保留原背景；轻度锐化不是AI高清修复。图组视频是固定帧序列编码，不是生成式动画。AI抠图、图片文字翻译、场景重绘、生成式视频待接入。素材库关联商品保留已生成版式，图片需重新核对。

本地构建包含单独调用的FFmpeg 7.1可执行文件，构建配置和许可证说明在应用的 Contents/Resources/ThirdParty。对外发行的对应源码及完整依赖许可资料仍待整理，本构建用于本机开发验证。


## 0.5 Codex 订阅与自动化

在「模型服务」点击「检查登录与额度」。本机需安装 Codex 并使用 ChatGPT 登录；应用不内置或复制 Codex 的登录令牌，也不需要 OpenAI API Key。新增服务默认选择订阅，直接选择 Luna 或 Sol，设置本软件的每日调用上限并启用；在「任务分工」将其分配给批量处理和内容复核。测试连接会实际消耗订阅用量，保存和检查登录不会调用模型。

「自动化中心」可为多件商品安排一次定时流程：货源核对、双语生成、模型复核、图片模板、资料检查、人工审核，再按显式设置提交 noon。关闭应用/电脑休眠时不执行；到期未运行的预约在下次启动处理。当前尚无常驻云端服务或循环规则触发器。

订阅请求通过官方本机 App Server，使用短期会话、只读工作空间和结构化输出。模型处理资料，普通程序负责队列、图片模板与数据库操作。模型目录只作选择参考，成功返回一次任务才确认该次调用。软件不购买积分、不兑换重置卡、不自动切换 API。

订阅额度在调用前重新查询；已知额度耗尽时自动化流程等待恢复时间，读取失败或未知窗口则停止提示。已发出的请求超时、中断或失败会保留待核对记录，不自动重放。同账号的其他 Codex 活动仍可能在查询后消耗额度，因此一次预检不能保证后续请求一定成功。

本机当前账号已完成 Luna 生成与 Sol 复核的真实测试；尚未验证降级 Plus 后的吞吐、长时间运行或真实商品翻译质量。此连接器是本地自用版本；未来云端或商业对外接入需另行按官方授权方案设计。

增加收入/成本费用凭证、分次收付款、四币种原币余额、逐笔汇率、订单费用分摊、人工贡献核对和CSV导出。业务单据不会自动确认为收入费用，实际收付款也不重复计成本。当前为本地经营台账，不会操作银行，没有noon结算文件或银行接口。

## 0.9 备份与恢复

「备份与恢复」可以创建并下载包含素材的完整资料包，上传检查后安排下一次启动恢复。切换前自动留回退副本；进程中断后的切换回滚已测试。恢复后队列暂停、模型停用、商品审核重置，先核对外部业务状态再继续运营。macOS 安装版启用定时备份后会登记当前用户的 LaunchAgent，在应用关闭、用户仍登录时每5分钟启动一次到期检查；应用正在运行时由前台调度器接管，睡眠期间不运行，唤醒后继续检查。该任务只写本机备份，不上传云端。详细步骤及容量/凭证/加密限制见 workbench/README.md。原生页面已打开验收，0.9独立后端恢复与浏览器导入导出通过；本轮原生保存/选择文件对话框未完成复验。


## 0.15 批量原图归集

按「SKU__01.jpg」命名，或按「SKU/01.jpg」放入目录。SKU 可使用软件生成的店铺 SKU 或供应商货号，大小写严格一致；供应商货号不唯一时用店铺 SKU。目录层级只检查图片直属文件夹，不猜测更上层归属。支持 JPG / PNG / WebP，暂不接受 ZIP 或批量视频。

预览不会上传图片；确认商品归属并填写素材使用依据后才保存到本机素材库。导入时再次匹配，并检查实际图片内容。同一商品的相同原图复用已有记录，保留其原使用依据；不同商品不会因此合并。缺失或被修改的原文件不会误判为可复用。

每张独立保存，错误不影响其他图片；可暂停后继续。关闭页面或应用会丢失尚未处理的文件选择，重新选择同一批文件会检查重复。已导入原图可被批量图片制作匹配，但不会自动加入上架图片、通过质量验收或消耗生图额度。


## 0.16 订阅生图实测与失败记录

「模型服务」检查登录时也读取通道生图能力。能力声明仅说明运行环境支持；任务详情中的图片接收记录和输出才证明该次调用收到图片。能力未知或明确不支持时，生图会在发送前停止。

生图会话保留本机生图运行组件，继续关闭脚本执行、Shell、浏览器、插件及继承的 MCP 服务；不使用 API Key。文字任务保持原限制。服务只返回文字、失败或中断时，保存经过敏感信息过滤的说明，显示在「本次服务返回」。服务文字不当作指令执行，也不当作图片。

可解码但分辨率或画幅不符的输出以原尺寸保留，状态为「输出规格不符」，不可验收或加入商品，并暂停后续制作。可下载核对；点击「停用这张输出，允许另建制作」保留文件并解除该输出对批量预检的阻挡，不立即发起新的模型调用。
